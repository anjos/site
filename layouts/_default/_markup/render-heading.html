{{- /* Give a Markdown-authored heading the same icon its template-rendered counterparts get, so a project page reads consistently whether a section comes from the template ("Key publications") or from the body ("## Major achievements", which every project has). Only headings whose text is in the map below are decorated; everything else renders exactly as Hugo would by default, so this hook is safe to apply site-wide. The opening tag is assembled with printf and marked safeHTML rather than written as ``: Go's html/template cannot take an action in an element-name position and silently escapes the whole template into visible markup when you try. */ -}} {{- $icons := dict "major achievements" "achievements" "key publications" "outputs" "publications" "outputs" "research outputs" "outputs" "supervised theses" "theses" "software" "software" "datasets" "datasets" "teaching" "teaching" "media" "media" "profile photo" "photos" -}} {{- $icon := index $icons (lower .PlainText) -}} {{- $attrs := printf " id=%q" .Anchor -}} {{- if $icon -}} {{- printf "" .Level $attrs | safeHTML -}} {{- partial "icon.html" $icon -}} {{ .Text }} {{- printf "" .Level | safeHTML -}} {{- else -}} {{- printf "" .Level $attrs | safeHTML }}{{ .Text }}{{ printf "" .Level | safeHTML -}} {{- end -}}
