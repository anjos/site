{{- /* Featured research outputs, above the filterable list. Input: dict "refs" "data" Resolution is the same two-step lookup layouts/projects/single.html uses: match on `doi` first, then on `key` (Zotero's BetterBibTeX citation key). A ref that resolves to nothing is skipped rather than failing the build — data/outputs.json is regenerated from Zotero, so a hand-written ref can legitimately go stale between runs.
